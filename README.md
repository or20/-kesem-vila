# Villa Manager

מערכת PWA פנימית לניהול וילה להשכרה.

## מה יש בפנים
- דשבורד יומי
- ניהול הזמנות ואורחים
- מניעת חפיפות בתאריכים
- מקדמות, יתרות, פיקדון נזק ואמצעי תשלום
- יומן תפוסה חודשי
- הוצאות ורווח
- משימות ניקיון וטיפול בפיקדון
- WhatsApp לאורח
- גיבוי/שחזור JSON
- ייצוא CSV לאקסל
- עבודה אופליין אחרי התקנה

## הפעלה
פתחו את `index.html` בדפדפן כדי לבדוק.
כדי להתקין כ-PWA בטלפון, העלו את התיקייה לשרת HTTPS (למשל GitHub Pages / Netlify / Vercel) ואז בחרו "התקנה" בדפדפן.

## חשוב
גרסה זו שומרת את הנתונים מקומית במכשיר (LocalStorage). לסנכרון בין כמה טלפונים/מחשבים צריך לחבר backend כגון Supabase.
